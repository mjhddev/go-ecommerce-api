# Go E-Commerce API

A RESTful API for an e-commerce application built with Go, Gin, GORM, PostgreSQL, and JWT Authentication.

## Tech Stack

- Go
- Gin
- GORM
- PostgreSQL
- JWT
- bcrypt
- godotenv

## Features

- [x] Gin Server
- [x] PostgreSQL Connection
- [x] GORM Integration
- [x] User Model
- [x] Auto Migration
- [x] User Registration
- [x] User Login
- [x] JWT Authentication
- [ ] JWT Authorization Middleware
- [ ] User Profile
- [ ] Category Management
- [ ] Product Management
- [ ] Shopping Cart
- [ ] Checkout
- [ ] Swagger Documentation
- [ ] Docker Support

## Run Project

```bash
go mod tidy
```

```bash
go run ./cmd/api
```
