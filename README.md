# Go E-Commerce API

RESTful E-Commerce API built with Go, Gin, GORM, and PostgreSQL.

## Tech Stack

- Go
- Gin
- GORM
- PostgreSQL

## Features

- [x] Gin Server
- [x] PostgreSQL Connection
- [x] GORM Integration
- [x] User Model
- [x] Auto Migration
- [ ] User Registration
- [ ] User Login
- [ ] JWT Authentication
- [ ] Category Management
- [ ] Product Management
- [ ] Shopping Cart
- [ ] Checkout
- [ ] Swagger Documentation
- [ ] Docker Support
